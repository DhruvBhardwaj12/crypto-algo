# LAB-20260923 — Time-Series Momentum (TSMOM)

**Hypothesis (one sentence):**
When an asset's trailing return over the past week is positive, it will
continue to rise over the following days; when negative, it will continue
to fall.

**Mechanism (why should this edge exist?):**
Momentum is one of the most documented anomalies across asset classes
(Moskowitz, Ooi, Pedersen 2012, "Time Series Momentum", JFE). It has been
observed in equities, bonds, commodities, currencies, and crypto. The
proposed mechanisms include: slow information diffusion, investor
under-reaction followed by over-reaction, and risk-management feedback
loops (funds scaling in as trends establish).

**Data used:**
BTCUSDT and ETHUSDT USDT-M perpetual futures, 4H bars, 2020-01-01 to
2025-01-01.

**Timeframe:**
4H entry and rebalance.

**Cost model:**
5 bps per side (futures taker).

**Parameters tested:**
  - lookback_n = 42 (1 week of 4H bars)
  - Long-only (signal in {0, 1})

**Rule:**
  - At close of each 4H bar, compute return over last 42 bars.
  - If > 0 → target position = 1 (long).
  - If ≤ 0 → target position = 0 (flat).
  - Execute at next bar's open.

**In-sample result:**

BTC:
  - Sharpe: 0.88
  - CAGR:   33.6%
  - Trades/year: 75
  - Max drawdown: −75.5%
  - Profit factor: 1.27

ETH:
  - Sharpe: 1.21
  - CAGR:   67.3%
  - Trades/year: 74
  - Max drawdown: −53.9%
  - Profit factor: 1.30

**Verdict:** PROMISING — passed the first screen. Better Sharpe and CAGR
than EXP-004 on both symbols, but with higher turnover and a worse BTC
drawdown. In-sample only. Requires full validation.

**Next step:** full validation (parameter sweep, walk-forward, regime,
bootstrap) on both symbols.

**Notes:**
- Same rule, both symbols: long when close/close.shift(42) > 1, else flat.
- Entry executes next 4H bar open. 5 bps per side.
- Strategy is single-parameter (lookback = 42). Wide sweep feasible
  without overfitting risk.
